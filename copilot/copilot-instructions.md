# Global Agent Rules

## Git

- Never run `git commit`, `git push`, `git rebase`, `git reset --hard`, `git commit --amend`, or any other command that changes git history or commits changes. Always leave staging, committing, and pushing to the user.

## Reports

When writing markdown formatted reports to file, keep these things in mind:

- Avoid long texts in markdown tables; prefer using structured lists.
- Pad cells in markdown tables so the column separators (`|`) align across all rows (and header).
